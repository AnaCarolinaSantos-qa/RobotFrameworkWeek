# Robot Framework Week

Material de referência criado para a Robot Framework Week.

## Instalações

- Python
- pip
- Robot Framework: `pip install robotframework`
- Robot Framework Selenium Library: `pip install robotframework-seleniumlibrary`

## Testes

O comando abaixo é um exemplo para uma suíte em `web/tests`:

```bash
robot -d ./log web/tests
```

No branch atual, o repositório contém apenas este README; a pasta `web/tests` não está versionada, então o comando não pode ser executado neste checkout.
